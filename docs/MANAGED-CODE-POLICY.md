# MetaVoiceType Managed Code Policy

MetaVoiceType application code is implemented in C#.

Use maintained C#/.NET libraries and wrappers.

Official precompiled native dependencies used internally by those wrappers are allowed.

Do not modify or build custom C/C++ versions of sherpa-onnx, ONNX Runtime,
Vosk, CUDA integrations, or similar dependencies unless the project owner
explicitly authorizes it.
